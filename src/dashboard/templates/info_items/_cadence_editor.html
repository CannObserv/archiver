{# Cadence editor - the announced fetch cadence (archiver#158), as a view/edit row (archiver#181). One of the panel's editable fields, one per row below the read-only rows. Follows the pattern Domains established in #176: a readout of the stored value beside a row-level "Edit", flipping to the control beside "Cancel" + "Save". It was a bare select plus a "Set" button, which is the only editable field on the dashboard that committed without an explicit edit gesture. Toggle is the generic `editableField` Alpine component (main.js), reached through `x-ref="field"`; Cancel restores each option's `defaultSelected` client-side, no server call. The edit half carries the inline `display:none` FOUC hint - the `settings/_api_key_row.html` trade rather than the `domains/_notes_partial.html` one. There is no no-JS save path to strand here: `watch-cadence` answers with a bare fragment rather than a 303, and this form only ever posted over HTMX. Posts to /dashboard/info-items/{id}/watch-cadence, which writes info_items.watch_spec and announces it on info.registry. hx-swap="none" like its sibling action forms: the section root carries hx-trigger="watcherUpdated from:body", and the response's HX-Trigger fires it, so the panel re-renders itself once. Swapping the response in *and* firing the trigger would render twice. Gated on has_active_source - cadence is Archiver's own policy, but announcing it for an unannounceable item burns a generation. Included from the `watching` AND `no_status` branches of _watcher_section.html: a freshly registered item sits in no_status until Watcher's first status frame, which is exactly when an operator wants to revise the cadence they just picked. `not_watching` has no announceable source by definition and `degraded` shows an error, so neither includes this. The blank option is "delegate" - the consumer applies its own default, which may be a per-domain one rather than a global constant, and it is only reachable because the route replaces the document instead of merging into it. Vocabulary comes from src/dashboard/cadence.py via the route context, not a literal list here; the schema admits more intervals than the dropdown offers. #}
